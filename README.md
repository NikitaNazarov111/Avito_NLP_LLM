# Поиск статей справки Авито

Решение задачи ранжирования статей справки по пользовательскому запросу.

## Подход

1. HTML статей разбивается на смысловые секции.
2. Секции делятся на чанки с overlap.
3. Для поиска используются BM25, char TF-IDF и Qwen embeddings.
4. Кандидаты объединяются через RRF.
5. Финальное ранжирование выполняется CatBoostRanker.
6. Качество проверяется на calibration.f с помощью 5-fold cross-validation по query_id и метрики MAP@10.

## Результат

Лучший локальный результат: MAP@10 около 0.596.
